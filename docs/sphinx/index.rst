Python SDK
==========

Official Python client for Modus.

* **Modus** — day-to-day reads and chat
* **ModusManagement** — create, update, and deploy

Install::

   pip install modus-sdk

Authenticate with ``MODUS_API_KEY`` (create a token in the Modus app under
**Settings → API Tokens**).
